Marketing data analysis project using Python, Pandas, Plotly, and Seaborn to evaluate customer behavior, campaign response, and marketing ROI.
# Marketing Data Analysis

## Project Overview
This project analyzes customer marketing data to understand purchasing behavior, campaign response, and marketing channel performance.

## Objectives
- Clean and preprocess data
- Analyze customer behavior
- Evaluate marketing channels
- Understand ROI
- Explain why Machine Learning is needed

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly

## Key Insights
- Store and Web channels perform best
- Customer behavior differs significantly
- Campaign response is imbalanced
- Machine Learning can improve targeting and ROI

## Charts Included
- Marketing Channel Performance
- Campaign Response Distribution
- Income vs Spending
- Correlation Heatmap
- Purchases by Campaign Response

## Conclusion
Machine Learning is needed to predict customer behavior, improve marketing ROI, and optimize marketing strategy.
